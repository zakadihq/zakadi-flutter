# zakadi-flutter

Zakadi packages for Dart and Flutter.

- `packages/zakadi/` - `zakadi` on pub.dev: shared protocol constants and types.
- `packages/zakadi_sdk/`, `zakadi_sdk_platform_interface/`, `zakadi_sdk_android/`, `zakadi_sdk_ios/` - the federated Flutter plugin wrapping the native Zakadi SDKs (not yet started; see the `zakadi` repository, `spec/08-cross-platform-sdk.md`).

Status: pre-release.
